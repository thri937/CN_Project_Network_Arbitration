# Experiments Directory

CSV files generated by `demo:local` or the testbed experiment recorder are saved here.
Format:
`t_ms, scenario, arbitration_on, slice, demand_kbps, limit_kbps, used_kbps, dropped_kbps, queue_ms, latency_p50_ms, latency_p95_ms, jitter_ms, loss_pct, availability_pct, devices, contention_state, decision_id`
