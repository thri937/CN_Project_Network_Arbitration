Running it needs only Node.js and a Windows laptop. Once: npm install, then npm run setup, which writes the settings file and a secret token, then npm run build so the gateway can serve the phone page, and npm run seed to create the seven departments. Open PowerShell as administrator and run the firewall script, which opens port 8080 for the local network only. Then npm run dev starts all four programs. Turn on the Windows Mobile Hotspot, open localhost 5173 on the laptop and sign in as Admin. Phones connect to the hotspot and open 192.168.137.1 port 8080 slash join, or scan the QR code. If we have fewer than seven phones, browser tabs on the laptop or the agent program fill in the other departments.
