Conventional slice controllers trust network labels (5QI, slice type, a static priority) set at install time, not business value.

Here is the twist. Network equipment decides using the technical label given to each system when it was set up, often from a template, by whoever installed it. The canteen screens happened to be set up as URLLC, the premium type. The quality lab, which is regulated and cannot lose data, was set up as eMBB, the standard type. So when capacity runs short, a label-based controller protects the lunch menu and slows the lab. And without any controller at all it is worse: everyone waits in the same full queue, the clinic included. We will measure that later.
