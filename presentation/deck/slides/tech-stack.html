Tech stack

TypeScript, end to end

Web pages

  • React 18 + Vite
  • Tailwind CSS
  • TanStack Query
  • Recharts (live charts)
  • qrcode (join QR)
  • WebSocket + fetch streams

Slice gateway

  • Node.js http + net
  • ws (WebSocket)
  • Token buckets, queues
  • 20 ms scheduler
  • Probe meter
  • Zod validation

Controller

  • Express REST API
  • Zod validation
  • Socket.IO realtime
  • JWT sessions
  • Pino logs
  • File-backed data store

Test & network

  • Vitest + Supertest
  • demo:local test driver
  • Agent (software phone)
  • Windows Mobile Hotspot
  • PowerShell firewall script

One language across phone page, gateway, controller and tests: npm workspaces hold all six packages.

Everything is TypeScript. The two web pages, the operator dashboard and the department page on the phones, are React 18 built with Vite, styled with Tailwind, with TanStack Query for server data, Recharts for live charts and the qrcode library for join codes; the phone page talks to the gateway with a WebSocket and a streaming download. The slice gateway is plain Node.js, using its built-in HTTP and network modules and the ws WebSocket library; it contains our token buckets, queues, a 20 millisecond scheduler and the probe meter. The controller is Express with Zod validation, Socket.IO, JWT sessions, Pino logging and a data store saved to a file. Tests use Vitest and Supertest; a test driver runs six test cases end to end, and a small agent program acts as a phone when we do not have seven real ones. On the network side we use Windows Mobile Hotspot and a PowerShell script that opens the firewall for the local network only.
