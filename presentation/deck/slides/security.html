Security & reliability

Built to be trusted

Private control API

Loopback only, secret token. Phones can’t set limits.

Roles

Viewer · Manager · Admin, with JWT sessions.

Append-only audit

Decisions, overrides, removals: never edited.

Firewall: local only

Port 8080 opened to the hotspot subnet, nothing else.

Join codes

Rotate a code, or remove a device, from the dashboard.

Self-healing

Gateway restart → limits resent; phones rejoin by themselves.

Any decision can be read by the department it affected: transparency is part of the design.

Because this system cuts bandwidth for real departments, it has to be trustworthy. The control API that sets limits listens only on the laptop itself and needs a secret token, so a phone on the hotspot cannot change anything. Operators sign in with roles, viewer, manager or admin, and JWT sessions. The audit trail is append-only: decisions, overrides and device removals are recorded and never edited. Our firewall script opens only port 8080, and only to the local network. Join codes can be rotated, and any device can be removed, from the dashboard. And it heals itself: if the gateway restarts, the controller notices and resends the current limits, and each phone page joins its slice again on its own.
