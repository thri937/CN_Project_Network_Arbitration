The problem statement

What we set out to build

“Runtime Arbitration for Contended, SLA-Critical Enterprise Network Slices”

A department-aware, auditable alternative to generic priority-based degradation.

Detect contention on real traffic

Explain every decision + alternatives

Decide by department, not QoS class

Keep a permanent audit trail

Protect SLA-critical slices

Enforce limits on a real shared link

This is our problem statement: runtime arbitration for contended, SLA-critical enterprise network slices, a department-aware, auditable alternative to generic priority-based degradation. In practice the system must detect contention while traffic is flowing; decide which slices give up bandwidth using department and business context rather than QoS class; protect slices whose SLAs are critical; explain every decision, including the alternatives it considered; keep a permanent audit trail; and, in this project, actually enforce the new limits on a real shared link that real devices use, and measure the effect.
