# Slice portal (`@cn/portal`)

The website each **department device** opens. A phone on the hotspot goes to
`http://<laptop-ip>:8080/join`, enters its department's join code (or scans the QR code on the
dashboard) and becomes that department's slice.

The gateway serves this website from `apps/portal/dist`. **Run `npm run build` after changing
it**, otherwise phones get the old version.

## What the device can do

- **Join** a slice with a 6-character code: `CLN101` Clinic, `FAC201` Factory, `LAB401` Quality lab,
  `WHS301` Warehouse, `SEC601` Security, `OFF501` Office IT, `CAN701` Canteen.
- **Create demand**: a slider and presets (Idle, Light 30 %, Normal 55 %, Busy 80 %, Peak 100 %,
  Flood 200 % of baseline). The page opens a download stream at that rate. Local mode uses bytes
  generated by the gateway (no internet data); internet mode pulls real bytes through the ISP.
- **See its slice live**: current limit vs baseline and floor; demand, received rate and latency
  charts; SLA status for latency, jitter, loss, throughput and availability; and, when the slice
  has been cut, the controller's reason in plain English.
- **Follow the operator**: the dashboard can set this device's demand remotely, and the page shows when it does. There is no opt-out switch yet.

## How it measures

Every second the page sends a small probe through its own slice's queues and times the reply.
It reports the round-trip times to the gateway, which turns them into latency, jitter, loss and
availability. If no probe is answered, the value is shown as unknown (—), never as 0.

## Device identity

The joined slice is stored in **sessionStorage**, which is separate for every browser tab. So
several tabs on one laptop can each be a different department. Closing the tab leaves the slice,
and you join again with the code. The nickname is remembered across tabs.

If the gateway restarts, the page joins the same slice again by itself. If the operator removes
the device on the dashboard, the page goes back to the join screen.

## Develop

```bash
npm run build -w @cn/portal
```

For phones, use the built files served by the gateway on `:8080`. `npm run dev -w @cn/portal`
starts a Vite dev server, which is for editing the UI on the laptop only.
