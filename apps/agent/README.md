# Slice agent (`@cn/agent`)

A command-line "device". It joins a slice and generates load exactly like the portal does
(download stream plus probes), with no browser. Use it on a spare laptop, or to fill slices that
have no phone.

```bash
npx tsx apps/agent/src/index.ts --gateway http://192.168.137.1:8080 --code CAN701 --name canteen-laptop --rate 280
```

| Flag | Default | Meaning |
|---|---|---|
| `--gateway` | `http://127.0.0.1:8080` | The gateway's address (from `npm run lan:info`) |
| `--code` | required | The slice's join code, e.g. `CLN101` |
| `--name` | `<hostname>-Agent` | Nickname shown on the dashboard |
| `--rate` | `50` | Demand in kbps |
| `--mode` | `local` | `local` = gateway-generated bytes; `internet` = real bytes through the ISP |
| `--duration` | `0` | Stop after this many seconds (0 = run until Ctrl+C) |
| `--probe-interval` | `1000` | Milliseconds between latency probes |

It prints a status line every few seconds: limit, received rate, round-trip p50/p95 and loss.

**Windows executable:** run `npm run build:agent:exe` to build `dist/slice-agent.exe` (Node single
executable application). Copy it to another Windows laptop and run it with the same flags, with no
Node.js needed.

`npm run demo:local` starts 7 of these agents in-process to run TC1–TC6 on one laptop.
